# ADR-004: Frontend & Mobile – React + Next.js for Web, React Native for Mobile

**Status:** Accepted  
**Date:** 2026-05-18  
**Deciders:** Nana Daasebre, Foureiratou ZAKARI (Frontend), Emmanuel Adoum

---

## Context

We need to deliver:
- A rich web dashboard with real‑time charts, heat maps, and configurable alerts.
- A mobile app (iOS/Android) with offline mode, push notifications, and biometric login.
- Reusable components across web and mobile (if possible).

Options:  
- Web: React, Vue, Svelte, Angular.  
- Mobile: React Native, Flutter, native (Swift/Kotlin).  
- Shared code: TypeScript + shared logic.

---

## Decision

- **Web:** Next.js 14 (React 18) + TailwindCSS + D3/Recharts.
- **Mobile:** React Native (Expo) with Expo Router.
- **Shared:** TypeScript for type definitions (risk categories, alert models).

---

## Rationale

- **React ecosystem** – Largest talent pool, reusable hooks, excellent real‑time support (WebSocket).
- **Next.js** – Server‑side rendering for initial load performance, API routes can proxy to backend, easy deployment.
- **React Native + Expo** – Single codebase for iOS, Android, and PWA. Expo handles builds, notifications (FCM), and biometrics.
- **TailwindCSS** – Rapid UI development with MTN brand colours.
- **D3/Recharts** – Flexible for risk radar, heat maps, Monte Carlo bands.

---

## Consequences

- **Positive:** Code reuse via shared TypeScript models; fast iteration on both platforms.
- **Negative:** React Native still has occasional bridge issues (but Expo manages well).  
  Heat maps may need optimisation for mobile.

---

## Alternatives Considered

- **Vue + Quasar** – Good but smaller team expertise.
- **Flutter** – Excellent performance but Dart required, no shared types with backend (Python/TypeScript mismatch).
- **Native iOS/Android** – Two codebases, double effort, not feasible for 6‑week timeline.

---

## Compliance

-  Real‑time dashboard – WebSocket client in React.
-  Mobile offline – Expo’s `expo‑file‑system` + PWA service worker.
-  Biometric – Expo LocalAuthentication.
